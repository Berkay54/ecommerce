# Form & Field design context

Warm off-white surfaces, dark forest text and restrained olive accents. Editorial typography pairs plain sans serif with a serif italic homepage accent. The store uses spacious image-led grids, thin rules and quiet category pills. Admin uses the same brand header and palette with structured forms and a simple product table. Mobile layouts stack naturally; keyboard focus remains visible and reduced-motion preferences are respected.

21st catalogue research: Shop by Category Grid (29288) and Ecommerce Category Page (29395). These informed category navigation and product grids; no external component source was installed. The CLI design-context initializer and review were unavailable in the offline package cache.
